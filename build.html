🚀 Сборка проекта

Выберите тип сборки и нажмите соответствующую кнопку для получения инструкций

Будут выполнены команды: npm install --legacy-peer-deps npm run build
💡 После сборки файлы будут доступны в папке .next/
Шаг 1: Синхронизация с Android
npx cap sync android
Шаг 2: Сборка APK
cd android ./gradlew clean ./gradlew assembleDebug
Шаг 3: Полная сборка Android
Полный процесс сборки Android: npm install --legacy-peer-deps npm run build npx cap sync android cd android ./gradlew clean ./gradlew assembleDebug
📦 APK файл будет создан в: android/app/build/outputs/apk/debug/
⚠️ Убедитесь, что у вас установлен Android Studio и настроен Android SDK
Будут выполнены команды: npm install --legacy-peer-deps npm run dev
🌐 После запуска откройте: http://localhost:3000
Дополнительные команды для разработки:
Проверка кода: npm run lint Запуск продакшн-сервера: npm run build npm run start Экспорт статической версии: npm run export
💡 Режим разработки включает горячую перезагрузку и отладку
