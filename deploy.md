# Инструкция по развертыванию приложения на Vercel через терминал

## Предварительные требования
- Установленный Node.js и npm/yarn/pnpm
- Установленный Vercel CLI
- Учетная запись на Vercel
- Доступ к репозиторию с исходным кодом приложения

## Установка Vercel CLI
1. Откройте терминал
2. Установите Vercel CLI глобально с помощью npm:
   ```bash
   npm install -g vercel
   ```
3. Войдите в свою учетную запись Vercel:
   ```bash
   vercel login
   ```

## Развертывание приложения
1. Перейдите в директорию вашего проекта:
   ```bash
   cd /path/to/your/project
   ```
2. Запустите процесс развертывания:
   ```bash
   vercel
   ```
3. Vercel запросит у вас несколько вопросов:
   - Имя проекта
   - Команда сборки (например, `npm run build`)
   - Команда запуска (например, `npm run start`)
   - Переменные окружения
4. После ответа на вопросы Vercel начнет процесс развертывания
5. После завершения развертывания Vercel предоставит вам URL вашего приложения

## Проверка развертывания
1. Перейдите по предоставленному URL, чтобы убедиться, что ваше приложение работает корректно

## Дополнительные команды
- Просмотр существующих проектов:
  ```bash
  vercel projects
  ```
- Просмотр логов развертывания:
  ```bash
  vercel deployments
  ```
- Удаление проекта:
  ```bash
  vercel rm <project-name>
  ```

## Troubleshooting
- Если ваше приложение не развертывается, проверьте логи развертывания с помощью команды `vercel deployments`
- Убедитесь, что все зависимости установлены и ваше приложение работает локально
- Проверьте, что команды сборки и запуска указаны корректно

## Заключение
Теперь ваше приложение развернуто на Vercel и доступно по указанному URL.
