# План исправления проблем гидратации

## Введение

В проекте обнаружены проблемы гидратации, которые возникают из-за несоответствия между HTML, сгенерированным на сервере, и свойствами клиента. Это может происходить по нескольким причинам:

1. Использование переменных, зависящих от времени или случайных значений
2. Форматирование дат и локалей
3. Клиентские API, недоступные на сервере

## Выявленные проблемы

### 1. Math.random() в components/ui/sidebar.tsx
**Проблема:** В компоненте `SidebarMenuSkeleton` используется `Math.random()` для генерации случайной ширины скелетона. Это вызывает несоответствие между сервером и клиентом.

**Решение:** Заменить случайную ширину на фиксированное значение или передавать ширину через props.

### 2. toLocaleString() в components/ui/chart.tsx
**Проблема:** Использование `toLocaleString()` для форматирования чисел может вызывать проблемы с локалью.

**Решение:** Заменить на фиксированный формат или использовать библиотеку для форматирования чисел.

### 3. toLocaleDateString() в components/ui/calendar.tsx
**Проблема:** Использование `toLocaleDateString()` для форматирования дат может вызывать проблемы с локалью.

**Решение:** Заменить на фиксированный формат даты или использовать библиотеку для форматирования дат.

### 4. toLocaleString() в components/shift-calendar.tsx
**Проблема:** Использование `toLocaleString("ru-RU", ...)` для форматирования дат может вызывать проблемы с локалью.

**Решение:** Заменить на фиксированный формат даты или использовать библиотеку для форматирования дат.

### 5. navigator.serviceWorker в app/page.tsx
**Проблема:** Использование `navigator.serviceWorker` в useEffect может вызывать проблемы, так как navigator недоступен на сервере.

**Решение:** Перенести этот код в useEffect с проверкой на наличие window.

## План действий

1. Исправить `Math.random()` в `components/ui/sidebar.tsx`
2. Исправить `toLocaleString()` в `components/ui/chart.tsx`
3. Исправить `toLocaleDateString()` в `components/ui/calendar.tsx`
4. Исправить `toLocaleString()` в `components/shift-calendar.tsx`
5. Проверить и исправить использование `navigator.serviceWorker` в `app/page.tsx`

## Ожидаемый результат

После внесения этих изменений проблемы гидратации должны быть устранены, и приложение будет корректно работать как на сервере, так и на клиенте.
