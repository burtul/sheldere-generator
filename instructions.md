# Инструкция по развертыванию приложения на Vercel

## Предварительные требования
- Установленный Node.js и npm/yarn/pnpm
- Учетная запись на Vercel
- Доступ к репозиторию с исходным кодом приложения

## Шаги для развертывания

### 1. Подготовка приложения
1. Убедитесь, что ваше приложение работает локально
2. Убедитесь, что у вас есть файл `package.json` в корне проекта
3. Убедитесь, что ваше приложение можно запустить с помощью команды `npm run dev` или аналогичной

### 2. Создание проекта на Vercel
1. Перейдите на [Vercel](https://vercel.com/)
2. Нажмите "Add New Project"
3. Выберите "Import Git Repository"
4. Выберите репозиторий с вашим приложением
5. Нажмите "Import"

### 3. Настройка проекта
1. Vercel автоматически определит настройки по умолчанию
2. Вы можете изменить настройки, такие как:
   - Имя проекта
   - Команда сборки (например, `npm run build`)
   - Команда запуска (например, `npm run start`)
   - Переменные окружения
3. Нажмите "Deploy" для развертывания вашего приложения

### 4. Проверка развертывания
1. После завершения развертывания Vercel предоставит вам URL вашего приложения
2. Перейдите по этому URL, чтобы убедиться, что ваше приложение работает корректно

### 5. Дополнительные настройки (опционально)
1. Настройка домена
2. Настройка SSL
3. Настройка вебхуков
4. Настройка переменных окружения

## Troubleshooting
- Если ваше приложение не развертывается, проверьте логи развертывания на Vercel
- Убедитесь, что все зависимости установлены и ваше приложение работает локально
- Проверьте, что команды сборки и запуска указаны корректно

## Заключение
Теперь ваше приложение развернуто на Vercel и доступно по указанному URL.
