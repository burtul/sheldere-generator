# Дорожная карта развития приложения "Shift Schedule Manager"

## Текущее состояние приложения

**Функциональность:**
- Генерация графиков смен 2/2 (день/ночь/выходные)
- Поддержка 4 бригад с разными паттернами смен
- Генерация 5-дневных графиков (8 часов и 8 часов 15 минут)
- Интерактивный календарь с цветовой кодировкой смен
- Отслеживание месячных норм часов
- Настраиваемые цвета для разных типов смен
- Заметки и уведомления для смен
- Список дел с отслеживанием выполнения
- Офлайн поддержка с сохранением в LocalStorage
- PWA-готовность (Progressive Web App)
- Мультиплатформенность (Web + Android через Capacitor)

**Технологический стек:**
- Next.js 16.1.1 с React 19.2.0
- TypeScript
- Tailwind CSS с Radix UI компонентами
- Capacitor для Android сборки
- Service Worker для офлайн работы
