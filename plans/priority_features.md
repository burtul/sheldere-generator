# Приоритетные функции для развития

## 1. Облачная синхронизация и многопользовательский режим

**Цель**: Реализовать синхронизацию данных между устройствами и поддержку нескольких пользователей.

### Технические требования:

- **База данных**: Firebase Firestore или Supabase
- **Аутентификация**: Firebase Auth или Auth0
- **Синхронизация в реальном времени**: WebSockets или Firestore listeners
- **Конфликтное разрешение**: Оптимистичные обновления с разрешение конфликтов

### Этапы реализации:

1. **Интеграция Firebase** (2 недели)
   - Настройка Firebase проекта
   - Интеграция Firebase Auth
   - Интеграция Firestore
   - Настройка правил безопасности

2. **Аутентификация пользователей** (1 неделя)
   - Регистрация/вход через email/пароль
   - Восстановление пароля
   - Социальная аутентификация (Google, Apple)
   - Сессии и управление токенами

3. **Синхронизация данных** (3 недели)
   - Миграция локальных данных в облако
   - Реализация синхронизации в реальном времени
   - Офлайн поддержка с автоматической синхронизацией
   - Разрешение конфликтов при одновременном редактировании

4. **Совместное использование графиков** (2 недели)
   - Возможность делиться графиками с другими пользователями
   - Управление правами доступа (чтение/запись)
   - Уведомления о изменениях в общих графиках

### Ожидаемые результаты:

- Пользователи могут входить в систему и синхронизировать данные между устройствами
- Возможность совместного использования графиков
- Автоматическая синхронизация изменений
- Офлайн работа с последующей синхронизацией

## 2. Расширенные типы графиков

**Цель**: Добавление поддержки дополнительных типов графиков смен.

### Новые типы графиков:

1. **3/1 график** (3 рабочих дня, 1 выходной)
   - Паттерн: Работа, Работа, Работа, Выходной
   - Настраиваемая длительность рабочего дня

2. **4/2 график** (4 рабочих дня, 2 выходных)
   - Паттерн: Работа, Работа, Работа, Работа, Выходной, Выходной
   - Варианты с разной длительностью смен

3. **Плавающий график** (настраиваемый паттерн)
   - Пользовательский паттерн смен
   - Возможность сохранения шаблонов
   - Применение к выбранным периодам

### Реализация:

1. **Расширение системы типов** (1 неделя)
   - Добавление новых типов смен в `lib/types.ts`
   - Расширение цветовых схем для новых типов

2. **Генерация графиков** (2 недели)
   - Новые функции генерации в `lib/schedule-utils.ts`
   - Поддержка пользовательских паттернов
   - Интерфейс для создания и редактирования паттернов

3. **Интерфейс пользователя** (2 недели)
   - Выбор типа графика в интерфейсе
   - Визуализация новых типов в календаре
   - Редактирование и настройка паттернов

### Ожидаемые результаты:

- Поддержка 5+ типов графиков
- Возможность создания пользовательских паттернов
- Гибкая настройка графиков для разных сценариев
